# Upstream ABCI protocol bindings

Protocol source: CometBFT tag `v0.40.0`, commit
`0880b4d378f347ab16e54ec677ff50d803f37d62` (Apache-2.0).
Go-specific protobuf options: cosmos/gogoproto `v1.7.2`, `gogoproto/gogo.proto`
SHA256 `a2bef0fb7e233ff2f442da08b3764be6ce59cc3f2df05cd1c9a44dbb5b55c18f`.
Its original copyright and BSD-style license notice are retained in gogo.proto.

Python files in the adjacent `proto/` directory are generated by grpcio-tools
1.82.2. Python imports are mechanically namespaced into
`computechain.blockchain.comet.proto`; protobuf message names, descriptors and
gRPC service routes are unchanged. Do not edit generated code by hand.

Regenerate with `scripts/generate_abci.py`. Upstream protocol sources are included
so the exact schema used by the adapter can be audited independently of the
Python implementation. The CometBFT license is included as `COMETBFT_LICENSE`.
